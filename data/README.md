# Data

Only public federal data or synthetic data I generated myself lives here.

- `raw/` is gitignored. Put API pulls and large downloads there.
- Cleaned files small enough to commit (under ~10 MB) can go in this folder,
  alongside a note saying where they came from and when they were retrieved.

Nothing from an employer belongs in this repository — no vendor lists, part
numbers, BOMs, invoices, drawings, or entry data.
